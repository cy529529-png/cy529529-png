# 你好，我是 cy529529-png 👋

我做电商产品三维视觉，日常工作覆盖**产品建模、材质、布光、渲染和画面交付**，也负责四人建模团队的质量目标与协作。现在我正把 AI、脚本和程序化方法带进实际制作流程，寻找真正能提高交付质量和效率的做法。

## 我的工作

- **跨品类产品制作**：根据产品资料和展示需求理解结构与卖点，完成模型、材质和电商展示画面。
- **场景与渲染**：使用 3ds Max、V-Ray 制作可继续修改的场景，关注比例、细节、光影、材质和最终画面表现。
- **团队协作与质量**：跟进四人团队的制作进度和质量目标，整理问题、反馈修改，并推动可复用的制作方法。

## AI + 3D 实践方向

我关注 AI 能否进入现有的三维生产流程，而不只是生成一张看起来相似的图片。目前主要探索：

- 用 AI 辅助参考整理、视觉方案、贴图处理和制作环节分析。
- 用脚本与程序化方法减少重复操作，尝试把纹理、建模和渲染流程做成可调整的工具。
- 将 AI 输出与 3ds Max / V-Ray 工作流衔接，让结果能检查、能修改、能继续交付。

## 我怎样判断工具有没有用

我会看产品的**形状、尺寸、零件、材质和多视角表现**是否准确，也会看结果是否可编辑、人工修复需要多久。真正有价值的提效，应当缩短**从输入到合格交付的总时间**，而不只是缩短生成这一步。
